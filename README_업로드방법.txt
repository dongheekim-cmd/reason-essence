이성과 본질 — 사이트 전체 방문자 1회 집계 수정본

- 한 사람이 여러 페이지를 보더라도 같은 GoatCounter 세션 안에서는 1회로 집계합니다.
- 모든 페이지가 동일한 경로 /site-visit 을 보내도록 수정했습니다.
- GoatCounter 기본 세션 시간은 약 8시간입니다.
- 앞으로 페이지별 방문수는 /site-visit 한 항목으로 합쳐집니다.
- 과거에 기록된 페이지별 통계는 그대로 남습니다.

업로드
1. 압축을 풉니다.
2. HTML 파일 6개를 저장소 최상위에 덮어씁니다.
3. css/footer-fix.css를 css 폴더에 덮어씁니다.
4. Commit changes를 누릅니다.
5. 반영 후 Ctrl+F5로 새로고침합니다.
