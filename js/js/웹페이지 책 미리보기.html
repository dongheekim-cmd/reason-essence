나의 말:

이성과_본질_웹사이트.zip
ZIP 아카이브

ChatGPT의 말:

맞습니다. 지금 들어간 것은 기능 확인용 임시 미리보기라서, 기존의 ‘책 소개·예상 독자·목차’를 다시 보여주는 수준입니다. 독자가 실제 책을 읽어보는 미리보기라고 하기는 부족합니다.

제대로 만들려면 책마다 다음처럼 구성해야 합니다.

  • 표지와 간단한 안내: 1쪽

  • 프롤로그 일부: 3~5쪽

  • 대표 장의 핵심 대목: 5~8쪽

  • 전체 약 5,000~8,000자

  • 마지막에 “미리보기는 여기까지입니다”

원문을 임의로 새로 쓰는 것보다 실제 원고에서 가져오는 것이 맞습니다. 우선 미리보기를 넣을 책의 통합원고 DOCX 파일을 올려주세요. 제가 프롤로그와 가장 매력적인 대표 장을 골라 적절히 발췌하고, 웹에서 읽기 좋게 문단을 다듬어 실제 본문 미리보기로 교체하겠습니다.

13권을 한꺼번에 하기보다 먼저 『경계선을 넘나드는 자연과학』 한 권을 완성형으로 만들어 확인한 뒤, 같은 방식으로 나머지 책에 적용하는 것이 좋겠습니다.


나의 말:

docx파일을 여기에 ?

ChatGPT의 말:

네, 이 대화창에 DOCX 파일을 첨부해 주세요.

우선 『경계선을 넘나드는 자연과학』 통합원고를 올려주시면 됩니다. 제가 원고에서:

  • 프롤로그의 매력적인 부분

  • 책의 성격을 잘 보여주는 대표 장

  • 약 5,000~8,000자 분량

을 골라 실제 책처럼 읽히는 미리보기로 만들고, 웹사이트 파일에도 넣어드리겠습니다.

원고 전체 공개가 걱정된다면 제가 분량을 제한해, 미리보기 마지막에 “이후 내용은 출간본에서 계속됩니다”라는 문구도 넣겠습니다.

ChatGPT의 말:

실제 원고를 넣은 수정본입니다.

이번에는 『경계선을 넘나드는 자연과학』에 다음 내용이 들어갑니다.

  • 프롤로그 3쪽

  • 1장 본문 4쪽

  • 총 약 5,500자

  • 마지막 문구: “이후 내용은 출간본에서 계속됩니다.”

GitHub에는 다음 세 파일을 올리거나 교체해야 합니다.

  • book.html

  • js/main.js

  • js/previews-data.js — 이번에 새로 생긴 파일

특히 previews-data.js를 반드시 GitHub의 js 폴더 안에 올려야 실제 원고가 나타납니다. 업로드한 뒤 상세 페이지에서 Ctrl + F5로 새로고침하면 됩니다.

ChatGPT의 말:

previews-data.js는 기존 폴더에 있던 파일이 아니라 이번에 새로 만든 파일입니다.

아래 파일을 직접 다운로드하세요.

폴더 안에 넣으시면 됩니다. 최종 위치는 다음과 같아야 합니다.
