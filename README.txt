아리스토텔레스 웹사이트 교체 패키지

이 패키지는 실행 파일이 없습니다.

1) ZIP을 풉니다.
2) ZIP 안의 폴더/파일 전체를 아래 저장소 루트에 그대로 복사합니다.
   C:\Users\dongh\Documents\이성과본질\6_웹사이트\reason-essence
3) 같은 파일이 있다는 창이 나오면 '대상 파일 바꾸기/덮어쓰기'를 선택합니다.
4) GitHub Desktop을 열면 변경 파일이 나타납니다.
5) Commit → Push origin.

반영:
- 제목: 아리스토텔레스라는 세계
- 부제: 자연과 인간을 하나의 체계로 읽다
- 표지: 새 표지
- 브라우저 이미지 캐시 방지를 위해 새 파일명 사용
