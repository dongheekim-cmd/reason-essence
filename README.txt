이성과 본질 웹사이트 수정 패키지

1. 이 ZIP의 모든 내용을 reason-essence 저장소 루트에 풉니다.
   예:
   C:\Users\dongh\Documents\이성과본질\6_웹사이트\reason-essence

2. apply_book_updates.bat 를 더블클릭합니다.

3. GitHub Desktop에서 변경 파일을 확인합니다.

수정 대상:
- js/books-data.js
- books/practical-reason.html
- books/philosopher-manual.html
- books.html
- images/books/practical-reason.webp

변경 내용:
- 실천이성의 귀환 → 도덕이 나라를 세운다
- 부제 → 이익의 시대, 시민의 도덕성으로 공동체를 다시 세우는 법
- 철학자의 인생 매뉴얼 부제 → 흔들리는 삶을 위한 25가지 철학의 질문

이 스크립트는 커밋이나 푸시를 하지 않습니다.
